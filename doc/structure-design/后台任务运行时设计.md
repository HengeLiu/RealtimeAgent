# 后台任务运行时设计

## 1. 文档目标

本文定义服务器侧 `backend-task-core` 和手机侧本地 `backend-task-core` 的统一设计，明确任务实例生命周期、调度方式、状态机、事件机制和跨端协作原则。

## 2. 设计目标

- 统一承接长生命周期任务
- 统一管理任务状态
- 支撑异步通知与查询
- 支撑多个任务并行存在
- 支撑服务器任务与手机本地任务的协作

## 3. 任务运行时定位

任务运行时负责：

- 创建任务实例
- 启动任务实例
- 推进状态机
- 记录任务上下文
- 发布任务事件
- 响应查询、暂停、取消、结束

任务运行时不负责：

- 用户自然语言理解
- 设备长连接细节
- 具体 Skill 底层实现

## 4. 核心组件

建议包括：

- `TaskManager`
- `TaskRegistry`
- `TaskStateMachine`
- `TaskScheduler`
- `TaskEventBus`
- `TaskContextStore`

## 5. 任务实例模型

任务实例由以下部分构成：

- 任务元信息
- 运行上下文
- 当前状态
- 事件历史
- 结果摘要
- 错误信息

## 6. 生命周期状态机

建议状态：

- `created`
- `queued`
- `preparing`
- `running`
- `waiting_input`
- `paused`
- `completed`
- `cancelled`
- `failed`
- `timed_out`

建议迁移：

- `created -> queued`
- `queued -> preparing`
- `preparing -> running`
- `running -> waiting_input`
- `waiting_input -> running`
- `running -> paused`
- `paused -> running`
- `running -> completed`
- `running -> cancelled`
- `running -> failed`
- `running -> timed_out`

## 7. 任务分类

第一阶段建议分为三类：

### 7.1 一次性短任务

示例：

- 拍照解读

### 7.2 定时 / 后台持续任务

示例：

- 计时器
- 定时检查画面变化

### 7.3 跨端协同任务

示例：

- 手机视频流任务
- 找物任务
- 导航任务

## 8. 任务模板设计

建议每个任务模板至少包含：

- `task_type`
- `validate_input()`
- `prepare()`
- `run()`
- `pause()`
- `resume()`
- `cancel()`
- `build_result()`

## 9. 任务事件机制

## 9.1 事件目标

- 向 Agent 报告任务进展
- 向设备发送通知
- 向日志系统输出结构化事件

## 9.2 建议事件类型

- `task.created`
- `task.started`
- `task.progressed`
- `task.waiting_input`
- `task.paused`
- `task.completed`
- `task.cancelled`
- `task.failed`

## 10. 任务上下文设计

任务上下文建议分为：

- `input_context`
- `runtime_context`
- `device_context`
- `result_context`

要求：

- 可序列化
- 可恢复
- 可记录摘要

## 11. 调度策略

第一阶段建议采用简单调度：

- 同一 `TaskManager` 内维护任务队列与活动任务表
- 高优先级任务优先启动
- 对同一资源冲突的任务交由上层资源管理器处理

不在第一阶段解决：

- 分布式任务调度
- 复杂抢占式调度

## 12. 与设备与Skill的关系

任务本身不直接操作硬件，建议通过 Skill 或设备网关完成动作。

例如：

- `timer_task` 到点后通过 `audio_play_skill` 通知眼镜
- `navigation_task` 通过 MCP 获取路线，再通过播报 Skill 输出
- `phone_video_link_task` 通过 `peer` 命令协调建链

## 13. 服务器任务与手机任务协同

### 13.1 协同原则

- 服务器任务是全局控制面
- 手机任务是本地执行面

### 13.2 协同方式

- 服务器创建全局任务
- 服务器向手机派生本地子任务
- 手机本地运行并持续回传状态

建议保留字段：

- `parent_task_id`
- `worker_device_id`

## 14. 查询与控制接口

建议支持：

- `task.create`
- `task.query`
- `task.state`
- `task.pause`
- `task.resume`
- `task.cancel`

## 15. 第一阶段建议的任务模板

- `timer_task`
- `photo_interpret_task`
- `navigation_task`
- `phone_video_link_task`

## 16. 测试建议

至少需要：

- 任务状态机测试
- 任务创建 / 取消测试
- 任务事件发布测试
- 一个跨端任务联调测试
