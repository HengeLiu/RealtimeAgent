# 回放测试断言能力设计

版本：sdk-v12

## 目标

回放测试不应只“跑完并保存日志”，还要能自动判断结果是否符合预期。本轮先把断言能力落到真实音频样例批量回归工具，覆盖语音入口、Agent 请求和能力调用轨迹。

## 已实现能力

`devtools.audio_sample_batch_runner` 新增：

1. `--expectations` 参数，读取 JSON 期望文件。
2. `defaults` 和 `cases.<sample_name>` 两级断言配置。
3. `reply_text_contains` / `reply_text_not_contains`。
4. `required_capability_traces`。
5. `model_request_contains`。
6. 每条 `result.json` 输出 `assertions_ok`、`assertion_failures`、`expectations`。
7. 断言失败会让单条样例 `ok=false`，并计入 `summary.failure_count`。

## 期望文件格式

```json
{
  "defaults": {
    "model_request_contains": ["qwen3.5-omni-plus"]
  },
  "cases": {
    "你是谁呀": {
      "reply_text_contains": ["乐鑫"],
      "reply_text_not_contains": ["抱歉"],
      "required_capability_traces": [
        {"capability_name": "capture_photo", "status": "succeeded"}
      ]
    }
  }
}
```

## 边界

本轮断言能力主要覆盖音频样例批量回归。`glass-playback` 设备级配置内断言、视频帧断言、端侧事件时间线断言和真实 iOS UI 日志断言仍需后续专项扩展。
