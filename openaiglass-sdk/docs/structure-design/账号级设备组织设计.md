# 账号级设备组织设计

版本：sdk-v9

## 目标

本轮把“多设备组织和账号级管理”收敛为 SDK 运行时能力，而不是业务能力。SDK 负责维护账号、设备、设备组和绑定关系的结构化索引，让功能开发者只表达设备归属和绑定意图。

## 范围

已实现：

1. `device.register` 可携带 `account_id` 和 `user_id`。
2. `DeviceGroupRuntime.register_device()` 支持账号字段。
3. `DeviceGroupRuntime.bind_devices()` 拒绝跨账号绑定。
4. `runtime.device_groups.accounts[]` 输出账号级设备、设备组和绑定快照。
5. 只有一方声明账号时，绑定后 SDK 会把同组设备归入该账号，兼容旧设备。

不在本轮范围：

1. 完整组织树、角色权限、授权策略和审计后台。
2. 远程设备目录和配置中心。
3. 多实例服务之间的设备状态同步。

## 注册消息扩展

```json
{
  "name": "device.register",
  "payload": {
    "device_id": "glass-001",
    "device_type": "glass",
    "account_id": "acct-demo",
    "user_id": "user-demo",
    "auth": {
      "mode": "pair_token",
      "pair_token": "pair-demo-token"
    }
  }
}
```

`account_id` 是设备组织边界。两个设备都声明账号时，账号必须一致才能绑定。

## 运行态快照

```json
{
  "device_groups": {
    "accounts": [
      {
        "account_id": "acct-demo",
        "user_id": "user-demo",
        "device_ids": ["glass-001", "phone-001"],
        "group_ids": ["group_xxx"],
        "online_device_count": 2,
        "bindings": [
          {
            "group_id": "group_xxx",
            "glass_device_id": "glass-001",
            "phone_device_id": "phone-001"
          }
        ]
      }
    ]
  }
}
```

## 业务开发边界

功能代码不要自行维护全局设备表。需要当前任务相关设备时，使用 `DeviceGroupContext.require_glass()`、`require_phone()`、`query_devices()`；需要账号级观察时，读取运行态快照或等待 SDK 后续提供更高层查询 API。
