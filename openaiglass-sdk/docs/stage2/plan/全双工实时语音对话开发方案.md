# 全双工实时语音对话开发方案

更新时间：2026-04-28

## 1. 开发原则

1. SDK 只补系统能力，不写业务功能。
2. 先补协议模型和测试夹具，再接真实模型和真机链路。
3. 服务端运行时、端侧协议和播放仲裁必须按同一状态机开发。
4. 每个迭代都要保证现有半双工语音链路和播放仲裁测试继续通过。

## 2. 迭代 A：协议模型与快照字段

开发内容：

1. 新增实时语音会话配置模型：输入格式、输出格式、打断策略、降级策略。
2. 新增实时事件模型：`input.started`、`input.delta`、`input.committed`、`user_interrupt`、`output.delta`、`output.completed`、`session.closed`。
3. 新增快照字段：实时会话状态、活动输入流、活动输出流、最近实时事件、延迟指标。
4. 保持 `voice.session.open` 的半双工兼容行为。

验收点：

1. 协议模型可以序列化/反序列化。
2. 半双工消息不需要迁移即可继续使用。
3. 快照中能区分 `half_duplex` 与 `full_duplex_realtime`。

## 3. 迭代 B：服务端实时运行时骨架

开发内容：

1. 新增 `RealtimeVoiceRuntime`，负责会话打开、关闭、状态迁移和事件记录。
2. 新增输入流缓冲和输出流缓冲，不把二进制媒体塞进控制消息。
3. 新增状态机守卫，禁止乱序事件直接污染上下文。
4. 增加 DEBUG 级别日志，记录会话、流、状态迁移和错误原因。

验收点：

1. 能用单元测试模拟完整打开、输入、输出、关闭流程。
2. 乱序输入能得到结构化错误。
3. 状态机快照能解释当前停在哪一步。

## 4. 迭代 C：播放仲裁与用户打断贯通

开发内容：

1. 把实时模型输出转为 `PlaybackIntent(source=agent_reply)`。
2. 把 `voice.realtime.user_interrupt` 转为 `UserInterruptEvent`。
3. 用户打断普通 Agent 回复时，取消当前输出流并下发 `actuator.audio.interrupt`。
4. 用户打断 critical 视觉告警时，按 `PlaybackArbiter` 策略延后处理。
5. 在快照中记录最近打断事件和仲裁决策。

验收点：

1. 播放中用户插话可以停止当前 Agent 输出。
2. 高优先级视觉告警不会被普通插话直接吞掉。
3. 所有打断都有可测试的 `reason`。

## 5. 迭代 D：实时模型 Adapter 与半双工降级

开发内容：

1. 定义 `RealtimeModelAdapter` 接口，屏蔽模型供应商差异。
2. 提供 `LoopbackRealtimeModelAdapter` 用于单测和回放。
3. 提供 `HalfDuplexFallbackAdapter`，实时模型不可用时复用现有 ASR + 流式 TTS 路径。
4. 建立模型取消、输出丢弃和最终文本提交语义。

验收点：

1. 单测不依赖真实模型供应商。
2. 实时模型不可用时能结构化降级。
3. 模型输出被用户打断后，迟到分片不会继续播放。

## 6. 迭代 E：回放测试与延迟断言

开发内容：

1. 扩展 SDK 回放测试格式，支持双向媒体帧和实时事件时间线。
2. 增加回声注入样例：下行音频被重新采到上行时不能误触发打断。
3. 增加用户插话样例：播放期间用户有效语音必须触发打断。
4. 增加延迟断言：首个模型增量、首个下行音频、打断决策耗时可配置阈值。

验收点：

1. 回放能稳定复现插话、回声、延迟和关闭。
2. 断言失败时报告具体时间点和事件编号。
3. 测试产物能帮助真机问题复盘。

## 7. 迭代 F：端侧/手机侧协议包与真机联调

开发内容：

1. 在端侧 SDK 契约中补实时语音消息和媒体帧定义。
2. 在 iOS SDK 契约中补可选中继、音频路由和资源观测字段。
3. 补真机联调启动顺序和观察点。
4. 更新 `SDK安装与能力开发指南.md`，说明业务开发者如何选择半双工或全双工模式。

验收点：

1. 端侧、手机侧、服务端能按同一协议抓日志。
2. 功能开发者不需要直接处理播放器抢占、用户打断和会话降级。
3. 真机联调文档能定位端侧 AEC、服务端仲裁、模型首包延迟三类问题。

## 8. 建议开发命令

每轮至少执行：

```bash
PYTHONPATH=openaiglass-sdk/server-python:openaiglass-for-blind uv run --with pytest python -m pytest openaiglass-sdk/tests/unit -q
python -m compileall -q openaiglass-sdk/server-python
git diff --check
```

涉及 iOS 或端侧包时追加对应平台测试。涉及真机联调时，必须保留服务端日志、设备日志和回放产物。
