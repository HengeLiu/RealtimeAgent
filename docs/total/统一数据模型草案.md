# 统一数据模型草案

## 1. 文档目的

本文档定义系统中跨模块、跨运行时共享的核心数据模型，供以下场景统一复用：

- 眼镜、手机、服务器三端通信
- 后台任务创建、运行、收尾
- 感知采集请求与仲裁
- 执行器播报、震动、提示控制
- 状态上报、日志记录、错误处理

本文档只定义“公共数据对象”，不直接约束具体传输协议格式。传输层封装见后续协议文档。

---

## 2. 设计原则

- 优先定义跨模块共享对象，而不是某个模块的私有结构
- 公共字段要尽量稳定、可扩展、可序列化
- 字段命名尽量中性，不绑定某一种传输协议
- 能用枚举的地方尽量用枚举，避免自由文本失控
- 先覆盖“寻找物体”黄金案例，再保证能扩展到其他任务

---

## 3. 基础标识模型

### 3.1 `DeviceId`

#### 说明

设备的唯一标识。

#### 建议格式

```json
"glass-001"
```

#### 约束

- 全局唯一
- 人类可读
- 不建议用临时随机值作为长期设备 ID

---

### 3.2 `SessionId`

#### 说明

任务实例或一次运行会话的唯一标识。

#### 建议格式

```json
"tasksess_20260402_0001"
```

---

### 3.3 `MessageId`

#### 说明

单条消息的唯一标识，用于 ACK、重试和日志追踪。

#### 建议格式

```json
"msg_01JQXYZ123ABC"
```

---

## 4. 设备与运行时模型

### 4.1 `RuntimeType`

#### 枚举值

```json
["glass", "phone", "server"]
```

---

### 4.2 `DeviceInfo`

#### 说明

描述一个设备或运行时节点的基础信息。

#### 字段

```json
{
  "device_id": "glass-001",
  "runtime": "glass",
  "display_name": "主眼镜",
  "online": true,
  "capabilities": ["rgb_camera", "imu", "speaker", "vibrator"],
  "network": {
    "control_connected": true,
    "peer_connected": false
  },
  "last_seen_at": "2026-04-02T10:15:00+08:00"
}
```

#### 字段说明

- `device_id`
  - 设备唯一 ID
- `runtime`
  - 运行时类型
- `display_name`
  - 用户可读名称
- `online`
  - 当前是否在线
- `capabilities`
  - 当前设备具备的能力集合
- `network`
  - 当前控制面和对等连接状态
- `last_seen_at`
  - 最近心跳或在线时间

---

### 4.3 `CapabilityType`

#### 建议枚举值

```json
[
  "rgb_camera",
  "depth_camera",
  "imu",
  "microphone",
  "speaker",
  "vibrator",
  "gps",
  "local_detection",
  "ocr",
  "map_navigation",
  "cloud_vlm"
]
```

## 5. 任务模型

### 5.1 `TaskDefinition`

#### 说明

任务模板定义，描述“这是什么任务”和“它通常如何运行”。

#### 示例

```json
{
  "task_name": "find_object",
  "task_category": "background",
  "description": "寻找用户指定物体",
  "executor_mode": "hybrid",
  "participants": ["glass", "phone", "server"],
  "input_schema": {
    "target_name": "string"
  },
  "phases": [
    "created",
    "starting",
    "waiting_stream",
    "scanning",
    "guiding",
    "completed",
    "failed",
    "cancelled"
  ],
  "required_capabilities": {
    "glass": ["rgb_camera", "speaker"],
    "phone": ["local_detection"],
    "server": ["task_orchestration"]
  },
  "capture_policies": [
    {
      "sensor": "rgb_camera",
      "mode": "stream",
      "default_fps": 5
    }
  ]
}
```

#### 核心字段

- `task_name`
  - 任务模板名称，例如 `find_object`
- `task_category`
  - 任务类别，例如 `interactive`、`background`、`system`
- `executor_mode`
  - 执行方式，例如 `glass_only`、`server_only`、`hybrid`
- `participants`
  - 预计参与端
- `input_schema`
  - 任务输入参数定义
- `phases`
  - 任务可能经历的阶段集合
- `required_capabilities`
  - 各运行时的必需能力
- `capture_policies`
  - 默认采集策略

---

### 5.2 `TaskCategory`

#### 建议枚举值

```json
["interactive", "background", "scheduled", "system"]
```

---

### 5.3 `ExecutorMode`

#### 建议枚举值

```json
["glass_only", "phone_only", "server_only", "hybrid"]
```

---

### 5.4 `TaskSession`

#### 说明

某个任务模板的一次实际运行实例。

#### 示例

```json
{
  "session_id": "tasksess_20260402_0001",
  "task_name": "find_object",
  "status": "running",
  "phase": "guiding",
  "priority": "high",
  "created_at": "2026-04-02T10:16:00+08:00",
  "updated_at": "2026-04-02T10:16:13+08:00",
  "initiator": {
    "runtime": "server",
    "device_id": "server-main"
  },
  "participants": {
    "glass": ["glass-001"],
    "phone": ["phone-001"],
    "server": ["server-main"]
  },
  "input": {
    "target_name": "手机"
  },
  "last_state_summary": {
    "hint": "目标在左前方",
    "found": true
  },
  "result": null,
  "error": null
}
```

#### 核心字段

- `session_id`
  - 任务实例 ID
- `task_name`
  - 对应的任务模板名称
- `status`
  - 任务整体状态
- `phase`
  - 当前阶段
- `priority`
  - 优先级
- `initiator`
  - 发起者
- `participants`
  - 当前参与设备
- `input`
  - 任务输入参数
- `last_state_summary`
  - 最近一条摘要状态
- `result`
  - 完成结果
- `error`
  - 失败信息

---

### 5.5 `TaskStatus`

#### 建议枚举值

```json
[
  "created",

  "starting",
  "running",
  "paused",
  "completed",
  "failed",
  "cancelled"

```

---

### 5.6 `TaskPriority`

#### 建议枚举值

```json

```

## 6. 采集模型

### 6.1 `SensorType`

#### 建议枚举值

```json
[
  "rgb_camera",
  "depth_camera",
  "imu",
  "microphone",
  "battery",
  "gps"
]
```

---

### 6.2 `CaptureMode`

#### 建议枚举值

```json
["snapshot", "stream", "continuous_state"]
```

---

### 6.3 `CaptureRequest`

#### 说明

任务向 `sensor_hub` 提出的采集请求。

#### 示例

```json
{
  "request_id": "capreq_0001",
  "session_id": "tasksess_20260402_0001",
  "sensor": "rgb_camera",
  "mode": "stream",
  "priority": "high",
  "profile": {
    "fps": 5,
    "resolution": {
      "width": 640,
      "height": 480
    },
    "quality": "medium"
  },
  "consumer": {
    "runtime": "phone",
    "device_id": "phone-001",
    "component": "task_components.find_object"
  }
}
```

#### 核心字段

- `request_id`
  - 采集请求 ID
- `session_id`
  - 所属任务实例
- `sensor`
  - 传感器类型
- `mode`
  - 采集模式
- `priority`
  - 请求优先级
- `profile`
  - 采集参数
- `consumer`
  - 最终消费方

---

### 6.4 `CaptureProfile`

#### 示例

```json
{
  "fps": 5,
  "resolution": {
    "width": 640,
    "height": 480
  },
  "quality": "medium",
  "duration_ms": null,
  "extra": {
    "exposure_mode": "auto"
  }
}
```

#### 字段说明

- `fps`
  - 帧率，适用于流式采集
- `resolution`
  - 分辨率
- `quality`
  - 压缩或清晰度级别
- `duration_ms`
  - 单次持续时长
- `extra`
  - 预留扩展参数

---

### 6.5 `CaptureGrant`

#### 说明

`sensor_hub` 对采集请求仲裁后的结果。

#### 示例

```json
{
  "request_id": "capreq_0001",
  "granted": true,
  "effective_profile": {
    "fps": 4,
    "resolution": {
      "width": 640,
      "height": 480
    },
    "quality": "medium"
  },
  "reason": "shared_with_existing_stream"
}
```

#### 用途

- 表示请求是否被接受
- 表示是否发生降级或复用
- 便于任务理解当前实际采集能力

## 7. 事件模型

### 7.1 `EventType`

#### 建议枚举值

```json
[
  "voice_event",
  "capture_ready",
  "device_state_changed",
  "task_state_changed",
  "detection_result",
  "execution_feedback",
  "system_warning"
]
```

---

### 7.2 `VoiceEvent`

#### 说明

由 `event_detector` 在 VAD 后包装出的结构化语音事件。

#### 示例

```json
{
  "event_type": "voice_event",
  "device_id": "glass-001",
  "timestamp": "2026-04-02T10:15:52+08:00",
  "payload": {
    "text": "帮我找一下手机",
    "audio_ref": "audio://glass-001/20260402/001",
    "vad_confidence": 0.96
  }
}
```

#### 说明

- `text`
  - 结构化文本结果，可能来自眼镜本地事件感知或服务器 ASR
- `audio_ref`
  - 原始音频引用
- `vad_confidence`
  - VAD 置信度

---

### 7.3 `DeviceStateEvent`

#### 示例

```json
{
  "event_type": "device_state_changed",
  "device_id": "glass-001",
  "timestamp": "2026-04-02T10:20:00+08:00",
  "payload": {
    "state_name": "battery_low",
    "value": true
  }
}
```

---

### 7.4 `TaskStateEvent`

#### 说明

某个任务实例的阶段或状态变化事件。

#### 示例

```json
{
  "event_type": "task_state_changed",
  "session_id": "tasksess_20260402_0001",
  "timestamp": "2026-04-02T10:16:13+08:00",
  "payload": {
    "task_name": "find_object",
    "status": "running",
    "phase": "guiding",
    "summary": {
      "found": true,
      "last_hint": "目标在左前方"
    }
  }
}
```

## 8. 执行模型

### 8.1 `ExecutionType`

#### 建议枚举值

```json
["speech", "beep", "vibration", "mixed"]
```

---

### 8.2 `ExecutionRequest`

#### 说明

发送给 `executor_bus` 的执行请求。

#### 示例

```json
{
  "execution_id": "exec_0001",
  "session_id": "tasksess_20260402_0001",
  "type": "speech",
  "priority": "high",
  "payload": {
    "text": "目标在左前方，请稍微向左转",
    "voice": "default"
  },
  "policy": {
    "interruptible": true,
    "drop_if_busy": false
  }
}
```

---

### 8.3 `ExecutionFeedback`

#### 示例

```json
{
  "execution_id": "exec_0001",
  "status": "played",
  "timestamp": "2026-04-02T10:16:14+08:00"
}
```

#### 建议枚举值

```json
["queued", "playing", "played", "skipped", "failed", "interrupted"]
```

## 9. 检测结果模型

### 9.1 `DetectionResult`

#### 说明

本地技能或云技能输出的统一检测结果对象。

#### 示例

```json
{
  "session_id": "tasksess_20260402_0001",
  "result_type": "object_detection",
  "timestamp": "2026-04-02T10:16:12+08:00",
  "payload": {
    "target_name": "手机",
    "found": true,
    "position": "left_front",
    "score": 0.91,
    "bbox": {
      "x1": 102,
      "y1": 180,
      "x2": 230,
      "y2": 340
    },
    "distance_level": "near"
  }
}
```

#### 可复用字段

- `target_name`
- `found`
- `position`
- `score`
- `bbox`
- `distance_level`

---

### 9.2 `HintPayload`

#### 说明

任务组件生成的用户引导建议。

#### 示例

```json
{
  "session_id": "tasksess_20260402_0001",
  "hint_type": "guidance",
  "text": "目标在左前方，请稍微向左转",
  "priority": "high"
}
```

#### 说明

- 该对象常用于手机直接向眼镜发送引导建议
- 服务器可只接收状态摘要，不强制接收完整 hint

## 10. 错误模型

### 10.1 `ErrorInfo`

#### 示例

```json
{
  "code": "CAMERA_BUSY",
  "message": "相机当前被更高优先级任务占用",
  "retryable": true,
  "detail": {
    "sensor": "rgb_camera"
  }
}
```

#### 核心字段

- `code`
  - 机器可处理的错误码
- `message`
  - 人类可读错误信息
- `retryable`
  - 是否可重试
- `detail`
  - 扩展上下文

---

## 11. “寻找物体”案例映射

在“寻找物体”中，最核心会落到这几个模型：

- `TaskDefinition`
  - `task_name = find_object`
- `TaskSession`
  - 记录一次找物实例
- `CaptureRequest`
  - 由找物任务请求眼镜相机流
- `DetectionResult`
  - 手机侧返回目标检测结果
- `HintPayload`
  - 手机直接发给眼镜的语音引导
- `TaskStateEvent`
  - 手机或服务器向后台任务中心回传任务状态
- `ExecutionRequest`
  - 眼镜将播报内容送入执行总线
