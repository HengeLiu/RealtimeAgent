## 2. 总览说明

提示系统设置主要包括：

- 提示音开关
- 震动开关
- 优先使用语音还是震动
- 强度和音量偏好

该功能由服务器作为配置中枢，眼镜侧负责执行器生效。

---

## 3. 时序过程一：用户修改设置

```plantuml
@startuml
title 时序过程一：用户修改提示设置
autonumber
skinparam shadowing false

actor "用户" as User #F2F2F2
participant "server_gateway\n服务器接入层" as SG #FFF4CC
participant "agent_center\n智能体中心" as AC #FFF4CC
participant "skills_registry\n技能注册中心" as SK #FFF4CC
participant "glass_gateway\n眼镜接入层" as GG #DFF3E3
participant "device_control\n执行器控制" as DC #DFF3E3
participant "executor_bus\n执行总线" as EB #DFF3E3

User -> SG: 请求“以后优先震动提醒”
SG -> AC: 转给智能体
AC -> SK: 调用 settings_skill
SK -> GG: 下发执行器配置更新
GG -> DC: 更新震动/音频偏好
DC --> GG: 配置已生效
GG -> EB: 播报“设置已更新”
@enduml
```
