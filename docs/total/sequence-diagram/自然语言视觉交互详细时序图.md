## 2. 总览说明

自然语言视觉交互是一个典型的“开放式问答任务”：

1. 用户提出视觉相关问题
2. 眼镜侧抓拍或上传当前图像
3. 服务器智能体调用多模态模型理解图像与问题
4. 结果返回眼镜播放

---

```plantuml
participant "glass_gateway\n眼镜接入层" as GG #DFF3E3
participant "server_gateway\n服务器接入层" as SG #FFF4CC
participant "agent_center\n智能体中心" as AC #FFF4CC

User -> SH: 说“前面有什么”
SH -> VAD: 提交语音
VAD -> ED: 输出语音事件
ED -> GG: 发送结构化事件
GG -> SG: 上报事件
SG -> AC: 识别为视觉问答
AC -> SG: 请求当前图像
SG -> GG: 下发抓拍指令
GG -> SH: 注册抓拍请求
SH --> GG: 返回图片
GG -> SG: 上传图片
@enduml
```
