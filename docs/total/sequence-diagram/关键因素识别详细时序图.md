## 2. 总览说明

“关键因素识别”用于识别红绿灯、盲道、非机动车道等环境中的关键视觉因素。该功能建议抽象为统一任务模板，不同识别类型作为参数传入。

---

## 3. 时序过程一：任务创建

```plantuml
@startuml
title 时序过程一：关键因素识别任务创建
autonumber
skinparam shadowing false

participant "server_gateway\n服务器接入层" as SG #FFF4CC
participant "agent_center\n智能体中心" as AC #FFF4CC
participant "skills_registry\n技能注册中心" as SK #FFF4CC
participant "background_task_center\n后台任务中心" as BTC #FFF4CC

SG -> AC: 提供用户语音事件
AC -> SK: 调用 create_hybrid_task(key_factor_detection)
SK -> BTC: 创建任务并附带 factor_type
@enduml
```

## 4. 时序过程二：识别运行闭环

```plantuml
@startuml
title 时序过程二：识别运行闭环
autonumber
skinparam shadowing false

participant "task_components.key_factor_detection\n关键因素识别组件" as KF #DDEBFF
participant "local_skills.factor_detection\n关键因素识别技能" as FD #DDEBFF
participant "phone_gateway\n手机接入层" as PG #DDEBFF
participant "glass_gateway\n眼镜接入层" as GG #DFF3E3
participant "sensor_hub\n感知总线" as SH #DFF3E3
participant "executor_bus\n执行总线" as EB #DFF3E3
participant "server_gateway\n服务器接入层" as SG #FFF4CC

KF -> PG: 请求图像
PG -> GG: 请求下一帧
GG -> SH: 拉取相机帧
SH --> GG: 返回图片
GG --> PG: 发送图片
PG -> KF: 提供图片
KF -> FD: 执行因素识别
FD --> KF: 返回识别结果
KF -> GG: 直接发送播报建议
GG -> EB: 播报“前方红灯/检测到盲道”
KF -> SG: 上报识别状态
@enduml
```

---

## 5. 关键分支

- 不同 `factor_type` 对应不同模型和播报模板
- 可作为独立任务触发，也可被导航任务内部调用
