## 2. 总览说明

电源管理属于低优先级系统功能，但应明确基本链路：

- 眼镜端持续感知电量状态
- 当电量低、过热或异常时形成事件
- 服务器记录设备状态
- 必要时触发节能策略或通知用户

## 3. 时序过程一：电量异常上报

```plantuml
@startuml

participant "event_detector\n事件感知" as ED #DFF3E3
participant "glass_gateway\n眼镜接入层" as GG #DFF3E3
participant "server_gateway\n服务器接入层" as SG #FFF4CC
participant "state_log_store\n状态与日志存储" as LOG #FFF4CC
participant "executor_bus\n执行总线" as EB #DFF3E3

SH -> ED: 检测到低电量/过热
ED -> GG: 发送设备状态事件
GG -> SG: 上报设备事件
SG -> LOG: 记录电源状态
GG -> EB: 本地播报“电量较低”
@enduml
```
