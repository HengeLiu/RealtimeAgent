## 2. 总览说明

寻找通路与寻找物体类似，区别在于：

- 目标不是一个具体物体，而是一条可通行路径
- 手机侧技能可能使用毫米波、视觉分割、通路检测等算法
- 输出的是“向哪里走更安全”的引导建议

```plantuml
PD --> FP: 返回可通行方向/风险区

GG -> EB: 播报“向右走可通过”
FP -> SG: 上报任务状态
@enduml
```

## 5. 关键分支

- 若路径被动态障碍阻挡，则重新计算通路
- 若无明显可通路径，可向用户播报“请原地等待”
