# 时序图通用说明

## 1. 文档目的

本目录下的时序图文档用于细化各功能在三端架构下的详细时序，明确以下内容：

- 眼镜、手机、服务器三端模块之间的交互顺序
- 每个功能在真实运行过程中的阶段拆分
- 哪些消息走控制面，哪些数据走任务数据面
- 各阶段的关键状态流转和日志记录点

本文档作为公共前置说明，供所有功能时序图文档引用，避免在每个文档中重复书写相同的基础约束。

---

## 2. 通用前提

所有功能时序图默认遵循以下前提：

- 所有语音输入都必须先进入眼镜端 `sensor_hub`（感知总线）
- 语音信号必须先经过 `event_detector.vad` 检测，形成结构化语音事件
- 只有形成结构化语音事件后，才允许经由 `glass_gateway`（眼镜接入层）发送到服务器
- 所有采集请求都必须先进入 `sensor_hub` 仲裁，任务不能直接控制采集器
- 所有面向用户的语音、提示音、震动输出都必须先进入 `executor_bus`
- 控制面默认经服务器中转；大流量图片、视频、连续帧在必要时可走眼镜与手机之间的任务级数据通道
- 服务器负责记录任务状态和生命周期日志

## 3. 参与模块字典

### 3.1 眼镜侧

- `sensor_hub`：感知总线
- `event_detector.vad`：VAD 模块
- `event_detector`：事件感知
- `glass_gateway`：眼镜接入层
- `executor_bus`：执行总线
- `device_control`：执行器控制

### 3.2 服务器侧

- `server_gateway`：服务器接入层
- `event_router`：事件任务分发
- `agent_center`：智能体中心
- `skills_registry`：技能注册中心
- `mcp_registry`：MCP 接入中心
- `background_task_center`：后台任务中心
- `state_log_store`：状态与日志存储

### 3.3 手机侧

- `phone_gateway`：手机接入层
- `local_task_center`：本地任务中心
- `task_components.*`：具体任务组件
- `local_skills.*`：具体本地技能

---

## 4. 配色建议

建议所有时序图统一采用以下配色：

- 眼镜侧：浅绿 `#DFF3E3`
- 服务器侧：浅黄 `#FFF4CC`
- 手机侧：浅蓝 `#DDEBFF`
- 用户：灰色 `#F2F2F2`
