## 2. 总览说明

后端用户数据管理当前以“日志优先”为主，目标是先把所有系统动作、任务状态和关键事件落日志，为后续管理页面做数据基础。

---

## 3. 时序过程一：统一日志记录

```plantuml
@startuml
title 时序过程一：统一日志记录
autonumber
skinparam shadowing false

participant "server_gateway\n服务器接入层" as SG #FFF4CC
participant "background_task_center\n后台任务中心" as BTC #FFF4CC
participant "agent_center\n智能体中心" as AC #FFF4CC
participant "state_log_store\n状态与日志存储" as LOG #FFF4CC

SG -> LOG: 写入设备接入/事件日志
BTC -> LOG: 写入任务生命周期日志
AC -> LOG: 写入智能体决策日志
LOG -> LOG: 归档与索引
@enduml
```

---

## 4. 关键分支

- 手机与眼镜之间直连的数据面不强制全量回传
- 服务器应至少保存状态摘要和关键节点
