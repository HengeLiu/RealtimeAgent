## 2. 总览说明

状态管理关注的是眼镜端休眠、激活、功能模式等设备运行状态，以及这些状态如何同步到服务器。

建议同时支持：

- 眼镜主动上报
- 服务器轮询查询

---

## 3. 时序过程一：状态主动上报

```plantuml
@startuml
title 时序过程一：状态主动上报
autonumber
skinparam shadowing false

participant "event_detector\n事件感知" as ED #DFF3E3
participant "glass_gateway\n眼镜接入层" as GG #DFF3E3
participant "server_gateway\n服务器接入层" as SG #FFF4CC
participant "state_log_store\n状态与日志存储" as LOG #FFF4CC

ED -> GG: 发送状态变化事件\n(休眠/激活/模式切换)
GG -> SG: 上报状态变化
SG -> LOG: 记录状态快照
@enduml
```

---

## 4. 时序过程二：服务器轮询查询

```plantuml
@startuml
title 时序过程二：服务器轮询查询
autonumber
skinparam shadowing false

participant "server_gateway\n服务器接入层" as SG #FFF4CC
participant "glass_gateway\n眼镜接入层" as GG #DFF3E3
participant "sensor_hub\n感知总线" as SH #DFF3E3

loop 周期轮询
    SG -> GG: 请求当前设备状态
    GG -> SH: 读取当前状态摘要
    SH --> GG: 返回状态摘要
    GG --> SG: 回传状态
end
@enduml
```

---

## 5. 关键分支

- 状态变化应尽量走主动上报，轮询仅作补充
- 功能模式切换时应同步到后台任务中心，避免状态与任务不一致
