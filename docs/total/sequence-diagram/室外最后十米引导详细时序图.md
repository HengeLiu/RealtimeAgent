## 2. 总览说明

“最后十米引导”是导航任务结束前的近场精细引导任务，目标通常不是抽象路线，而是入口、门牌、扶梯口、站点口等具体近场目标。

由于文档中也指出该功能仍有难点，本时序图先给出建议结构，具体识别算法后续再细化。

---

## 3. 时序过程一：由导航任务切换到近场引导

```plantuml
@startuml
title 时序过程一：切换到最后十米引导
autonumber
skinparam shadowing false

participant "task_components.outdoor_navigation\n导航组件" as NAV #DDEBFF
participant "background_task_center\n后台任务中心" as BTC #FFF4CC
participant "skills_registry\n技能注册中心" as SK #FFF4CC
participant "server_gateway\n服务器接入层" as SG #FFF4CC
participant "glass_gateway\n眼镜接入层" as GG #DFF3E3
participant "executor_bus\n执行总线" as EB #DFF3E3

NAV -> BTC: 上报已进入目标附近
BTC -> SK: 创建 last_meter_guidance 任务
SK -> BTC: 返回近场引导 TaskSession
BTC -> SG: 下发切换任务指令
SG -> GG: 通知眼镜进入近场引导模式
GG -> EB: 播报“进入最后十米引导”
@enduml
```

## 4. 时序过程二：近场目标引导闭环

```plantuml
@startuml
title 时序过程二：近场目标引导闭环
autonumber
skinparam shadowing false

participant "task_components.last_meter_guidance\n最后十米引导组件" as LM #DDEBFF
participant "local_skills.near_field_guidance\n近场引导技能" as NF #DDEBFF
participant "phone_gateway\n手机接入层" as PG #DDEBFF
participant "glass_gateway\n眼镜接入层" as GG #DFF3E3
participant "sensor_hub\n感知总线" as SH #DFF3E3
participant "executor_bus\n执行总线" as EB #DFF3E3
participant "server_gateway\n服务器接入层" as SG #FFF4CC

LM -> PG: 请求近场图像/深度信息
PG -> GG: 请求图像和深度帧
GG -> SH: 拉取相机/深度相机数据
SH --> GG: 返回感知数据
GG --> PG: 发送近场数据
PG -> LM: 提供输入
LM -> NF: 识别入口/目标点
NF --> LM: 返回偏移与距离
LM -> GG: 直接发送近场引导
GG -> EB: 播报“前方两米，稍向右”
LM -> SG: 上报阶段状态
@enduml
```

## 5. 关键分支

- 可由导航任务自动切入
- 也可由用户主动说“帮我找到入口”触发
- 若近场目标无法识别，可回退到一般通路检测
