## 2. 总览说明

这一类功能包含：

- 用户修改提示词
- 用户新增或编写 Skills
- 用户自定义知识库
- 用户设置记忆时长

这些功能本质上都属于“系统配置任务”，由服务器主导执行并持久化配置结果。

---

## 3. 时序过程一：用户提交配置请求

```plantuml
@startuml
title 时序过程一：用户提交配置请求
autonumber
skinparam shadowing false

actor "用户" as User #F2F2F2
participant "server_gateway\n服务器接入层" as SG #FFF4CC
participant "agent_center\n智能体中心" as AC #FFF4CC
participant "skills_registry\n技能注册中心" as SK #FFF4CC
participant "state_log_store\n状态与日志存储" as LOG #FFF4CC

User -> SG: 提出配置请求
SG -> AC: 转给智能体
AC -> AC: 解析为系统配置意图
AC -> SK: 调用对应配置 Skill
SK -> LOG: 记录配置变更申请
@enduml
```

## 4. 时序过程二：配置写入与生效

```plantuml
@startuml
title 时序过程二：配置写入与生效
autonumber
skinparam shadowing false

participant "skills_registry\n技能注册中心" as SK #FFF4CC
participant "agent_center\n智能体中心" as AC #FFF4CC
participant "state_log_store\n状态与日志存储" as LOG #FFF4CC
participant "server_gateway\n服务器接入层" as SG #FFF4CC
participant "glass_gateway\n眼镜接入层" as GG #DFF3E3
participant "executor_bus\n执行总线" as EB #DFF3E3

SK -> SK: 写入提示词/知识库/记忆参数
SK -> LOG: 记录配置结果
SK -> AC: 返回配置完成
AC -> SG: 生成确认通知
SG -> GG: 下发确认消息
GG -> EB: 播报“设置已更新”
@enduml
```

---

## 5. 关键分支

- 新增 Skill 可能需要校验或审核
- 记忆时长配置可能立即影响智能体上下文压缩策略
- 知识库更新可能影响后续问答结果
