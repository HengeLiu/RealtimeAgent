# 容器级模拟启动说明

## 1. 文档目的

本文档用于说明如何启动容器级模拟第一版。

## 2. 启动前准备

需要确保本机具备：

- Docker
- Docker Compose

同时建议先在本地跑过：

```bash
pytest nextgen/tests -q
```

## 3. 启动命令

在仓库根目录执行：

```bash
docker compose -f deploy/container-sim/docker-compose.yml up --build
```

## 4. 当前容器说明

当前 compose 包含四个服务：

- `glass-sim`
- `phone-sim`
- `server-sim`
- `find-object-runner`

前三个容器负责：

- 写出运行时探针文件
- 保持最小运行状态

最后一个容器负责：

- 等待三端探针就绪
- 执行标准找物场景
- 写出结构化结果文件

## 5. 当前限制

当前容器级模拟第一版仍然存在以下限制：

- 三端之间尚未进行真实跨容器消息通信
- 仍未回放真实音频和图像文件
- 当前结果更接近“容器边界验证”和“场景回放验证”

## 6. 验证重点

当前阶段建议重点检查：

- compose 是否能顺利构建
- 四个容器是否都能启动
- 共享卷中是否出现 `status` 和 `results` 文件
- `find_object_phone_center_001.json` 是否包含预期结果
