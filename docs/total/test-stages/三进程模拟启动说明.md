# 三进程模拟启动说明

## 1. 文档目的

本文档用于说明如何在当前仓库中运行“寻找物体”三进程模拟。

## 2. 当前实现入口

当前已经提供一个命令行脚本：

- `scripts/run_find_object_process_simulation.py`

该脚本会：

- 读取标准 `case_id`
- 调用三进程模拟器
- 输出结构化 JSON 结果

## 3. 推荐运行方式

若当前目录存在 `.venv`，推荐优先使用：

```bash
uv run python scripts/run_find_object_process_simulation.py --case-id find_object_phone_center_001
```

也可以直接使用：

```bash
python scripts/run_find_object_process_simulation.py --case-id find_object_wallet_missing_001
```

## 4. 推荐首批运行场景

建议按以下顺序运行：

1. `find_object_phone_center_001`
2. `find_object_wallet_missing_001`
3. `find_object_phone_grasp_001`

这三个场景分别验证：

- 正常发现目标
- 继续扫描
- 手接触目标后的引导结果

## 5. 输出结果说明

脚本输出为 JSON，主要包含：

- `case_id`
- `voice_case_id`
- `expected_hint_contains`
- `expected_final_status`
- `processes`
- `result`

其中 `result` 中最关键的是：

- `session_id`
- `phone_hint`
- `final_status`
- `task_log_snapshot`

## 6. 当前限制

当前脚本虽然命名为“三进程模拟”，但本质上仍属于“单机 Python 参考实现下的三端边界模拟”，尚未实现：

- 真实操作系统级三进程独立启动
- 真实网络链路隔离
- 真实音频或图片文件回放

因此这个脚本的定位是：

- 联调入口
- 行为参考实现
- 真机联调前的固定基线
