# 内部设计与阶段记录

本目录保存 `audio-chat` 的内部设计、阶段记录和迁移说明。它们不是秘密文档，但默认不作为社区开发者的稳定入口。

阅读这些文档时需要注意：

1. 文档可能包含历史设计、目标形态或阶段性判断。
2. 如果内部设计文档和当前使用说明冲突，以 `docs/getting-started/`、`docs/how-to/`、`docs/reference/` 和代码实现为准。
3. 面向社区稳定承诺的内容，应逐步沉淀到社区文档目录。
